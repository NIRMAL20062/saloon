# GLIDE is native Android now

The mobile client is Kotlin + Jetpack Compose, in `android-native/`. The Expo/React Native app has been removed — see `docs/NATIVE_ANDROID_PLAN.md` for why and `PROGRESS.md` for what's built so far.

Before writing any code, read `docs/NATIVE_ANDROID_PLAN.md` and `docs/NATIVE_ANDROID_SPEC.md`. The Supabase backend (`supabase/`) is unchanged and shared — nothing there needs re-reading in a new context, it's the same schema/RLS/Edge Functions the plan docs describe.
